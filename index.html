❤️ Sistema Circulatorio

Responsable del transporte de sangre, nutrientes, hormonas, oxígeno y células inmunes por todo el cuerpo.

Componentes principales:

  • Corazón
  • Arterias
  • Venas
  • Capilares
  • Sangre

🫁 Sistema Respiratorio

Permite la respiración y el intercambio de oxígeno y dióxido de carbono entre el cuerpo y el ambiente.

Componentes principales:

  • Pulmones
  • Tráquea
  • Bronquios
  • Alvéolos
  • Diafragma

🩲 Sistema Digestivo

Procesa los alimentos para extraer energía y nutrientes, eliminando los desechos no utilizables.

Componentes principales:

  • Boca
  • Esófago
  • Estómago
  • Intestinos
  • Hígado
  • Páncreas

🧠 Sistema Nervioso

Coordina las acciones del cuerpo mediante señales transmitidas entre el cerebro y diferentes partes del cuerpo.

Componentes principales:

  • Cerebro
  • Médula espinal
  • Nervios
  • Neuronas

💪 Sistema Muscular

Permite el movimiento del cuerpo y mantiene la postura mediante la contracción y relajación muscular.

Componentes principales:

  • Músculos esqueléticos
  • Músculos lisos
  • Músculo cardíaco
  • Tendones
